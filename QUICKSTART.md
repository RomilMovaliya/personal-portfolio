# 🚀 Quick Start Guide

Get your portfolio up and running in 15 minutes!

## Prerequisites
- Node.js 18+ installed
- Git installed
- GitHub account
- AWS account (free tier)

## Step 1: Customize Your Portfolio (10 minutes)

### Essential Updates
1. Open `app/layout.tsx` - Update title and description
2. Open `components/About.tsx` - Replace with your story
3. Open `components/Skills.tsx` - Add your skills
4. Open `components/Projects.tsx` - Add your projects
5. Open `components/Achievements.tsx` - Add your achievements
6. Open `components/Contact.tsx` - Update contact info
7. Open `components/SecretConsole.tsx` - Personalize commands

### Quick Find & Replace
Search for these and replace with your info:
- `Your Name` → Your actual name
- `your.email@example.com` → Your email
- `yourusername` → Your GitHub username
- `Your City, Country` → Your location

## Step 2: Test Locally (2 minutes)

```bash
cd portfolio
npm install
npm run dev
```

Open http://localhost:3000 and verify:
- ✅ All sections display correctly
- ✅ Links work
- ✅ Press `Ctrl+\`` to test the secret console
- ✅ Resize browser to test responsive design

## Step 3: Push to GitHub (2 minutes)

```bash
git init
git add .
git commit -m "Initial commit: My AWS Portfolio"
git branch -M main
git remote add origin https://github.com/yourusername/portfolio.git
git push -u origin main
```

## Step 4: Deploy on AWS Amplify (3 minutes)

1. Go to [AWS Amplify Console](https://console.aws.amazon.com/amplify/)
2. Click "New app" → "Host web app"
3. Select "GitHub" and authorize
4. Choose your repository and `main` branch
5. Click "Save and deploy"
6. Wait 3-5 minutes for deployment
7. Get your live URL!
