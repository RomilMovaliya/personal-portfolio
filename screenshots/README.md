## How to Take Screenshots

### For Portfolio
1. Deploy your portfolio to AWS Amplify
2. Open the live URL in your browser
3. Take screenshots of each section
4. Test the secret console (`Ctrl + \``) and screenshot it
5. Use browser DevTools to test mobile view
6. Screenshot mobile responsive layouts

### For AWS Setup
1. Log in to AWS Console
2. Navigate to Amplify service
3. Screenshot your app dashboard
4. Click into build details, screenshot success logs
5. Go to CloudFront, find your distribution, screenshot details

## Screenshot Guidelines

- Use full viewport screenshots
- Ensure text is readable
- Show the secret console in action
- Demonstrate responsive design
- Include AWS service details clearly

## Tools for Screenshots

- **Windows**: Win + Shift + S
- **Mac**: Cmd + Shift + 4
- **Chrome DevTools**: Device toolbar for mobile views
- **Browser Extensions**: Awesome Screenshot, Full Page Screenshot
